# Permis B1 — Code de la route

PWA для самостійної підготовки до іспиту з теорії ETG (Code de la route) у Франції
та до практичного іспиту з водіння. Усе французькою, як на іспиті, з кнопкою
«🇺🇦 Переклад» українською. Працює офлайн, встановлюється на телефон.

**Сайт:** https://volanderbo-stack.github.io/Permis-B1/

## Що всередині

| Розділ | Що є |
| --- | --- |
| **Code** (10 тем ETG) | 29 уроків-конспектів зі знаками, таблицями й «À retenir» + міні-тест після кожного; режими: продовжити, випадкові 20, нові, з помилками, усі |
| **Питання** | 639 власних питань (одна чи кілька правильних відповідей), складність, теги правил, пояснення fr/uk, 89 питань зі знаками, 16 схем перехресть «хто проїжджає першим» |
| **Examen blanc** | 40 питань (по 4 з кожної теми), 20 с на питання, «Corriger», озвучка французькою, без повторів з 5 останніх іспитів, розбір у кінці |
| **Révision** | інтервальне повторення (Лейтнер: 1-2-4-8-16-32 дні), помилки (зникають після 3 правильних поспіль), обране ★ і нотатки |
| **Entraînement** | своя серія: тема × тип (нові / з помилками / складні) × правило (тег) × 10/20/40 |
| **Panneaux** | 101 знак з Wikimedia Commons: картки, тест «знак → значення» і «значення → знак» |
| **Conduite** | формат практичного іспиту, 28 карток перевірок і першої допомоги, маневри, ситуації в русі, самооцінка навичок, щоденник занять, чекліст «день іспиту» |
| **Plus** | шпаргалка з усіма числами, словник FR → UK (185 термінів з озвучкою), пошук, статистика (графік іспитів, теплова карта, слабкі теми й правила), денна мета, резервна копія прогресу |

## Запуск

```bash
npm install
npm run dev          # локальний сервер розробки
npm run build        # продакшн-збірка в dist/
npm run check:data   # перевірка JSON з питаннями
npm run fetch:signs  # завантажити знаки з Wikimedia Commons у public/signs/
```

## Структура

```
src/
  data/
    questions/*.json     # питання, один файл на тему
    courses/*.json       # уроки, один файл на тему
    signs.json           # знаки: код, файл на Commons, значення fr/uk
    driving.json         # розділ «Conduite»
    glossary.json, memo.ts, tags.ts, themes.ts
  lib/                   # прогрес (localStorage), повторення, іспит, озвучка
  components/            # картка питання, схеми перехресть, уроки…
  pages/                 # сторінки застосунку
scripts/
  validate-questions.mjs # перевірка питань
  fetch-signs.mjs        # завантаження знаків
  describe-signs.mjs     # звірка значень знаків з описами Wikimedia
```

### Формат питання

```json
{
  "id": "q001",
  "theme": "circulation",
  "image": null,
  "scene": { "road": "cross", "vehicles": [{ "label": "A", "from": "S", "to": "N" }] },
  "question_fr": "...",
  "question_uk": "...",
  "answers": [{ "id": "A", "fr": "...", "uk": "..." }],
  "correct": ["A", "C"],
  "explanation_fr": "...",
  "explanation_uk": "...",
  "tags": ["priorite"],
  "difficulty": 2
}
```

`image` — шлях на кшталт `signs/AB4.svg` (знак з бази); `scene` — схема перехрестя (необов'язкова).

## Деплой

Workflow `.github/workflows/deploy.yml`: на кожен push — перевірка даних, лінтер,
завантаження знаків і збірка; публікація на GitHub Pages — лише з `main`.
У налаштуваннях репозиторію: **Settings → Pages → Source: GitHub Actions**.

## Важливо

Питання й уроки складені самостійно за правилами Code de la route, а не скопійовані
з платних баз. Застосунок неофіційний: числа (штрафи, бали, ліміти) іноді змінюються,
тож перевіряй актуальні правила на securite-routiere.gouv.fr і service-public.fr.
Формат практичного іспиту описано для категорії B; для B1 уточни в автошколі.

Знаки — Wikimedia Commons (французькі дорожні знаки, суспільне надбання).
